🌾 How We Build the Pookkalam

A simple, fun collaborative effort for Onam.

1

Add the Bot

Invite the bot to your Discord server using the button above.

2

Type a Command

Use /bloom or /paint to receive an interactive painting board.

3

Color a Petal

Select the recommended flower or pick your own from the traditional palette.

4

Observe Cooldown

To keep it collaborative, each member has a 3-minute cooldown before they can color again!
